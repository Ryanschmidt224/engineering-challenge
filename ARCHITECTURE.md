# Building Schmidt architecture

The current application uses Cloudflare Workers, D1 project/Workshop/Info Bits metadata, and R2 accounts, immutable files and backups. There is one owner account boundary and one current project engine. The retired R2 project application and its UI/API controllers have been removed.

See [the codebase guide](docs/CODEBASE_GUIDE.md), [current status](docs/STATUS.md), [project engine foundation](docs/PROJECT_ENGINE_FOUNDATION.md) and [whole-site backup](docs/SITE_DATA_BACKUP.md). Historical plans are under `docs/history/` and dated reports; they do not describe current runtime ownership.
