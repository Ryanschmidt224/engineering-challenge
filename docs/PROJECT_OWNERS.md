# Project owners and settings

New projects choose Ryan, Wes or Wyatt; Ryan is the default. Settings can change that label later. The Projects directory combines owner filtering with search, sort and view. These labels do not grant accounts access or change authentication.

Existing projects and older backups default to Ryan. Current streamed and small backup exports preserve the owner label, and restore validates it.

Existing-project Settings is a full page (`view=settings`) within the project workspace. It contains numbering, owner, automatic backups, project backup export and readable HTML export. New project remains a dialog. Unsaved settings are retained when switching workspace pages; Cancel discards them. Drafts retain their original revision so later saves still detect intervening changes. Reloading the browser discards an unsaved draft.

Permanent deletion is a separate sensitive change and is not included in this release.
